## 📌 Description
P2P Local File Share Server creates instant zero-configuration HTTP file sharing endpoints over the local network (LAN).

---

## ✨ Features
- Instant local web server creation for zero-install file transfers across LAN
- QR code generation for instant mobile phone connectivity and downloading
- Drag-and-drop file sharing queue with access permission controls
- PIN code authentication for secure peer-to-peer transfers
- Bandwidth monitor showing connected client streams and transfer speeds

---

## 🛠️ Tech Stack & Architecture
- **Language / Framework**: Python 3.10+ / Qt (PySide6 / PyQt)
- **Core Modules**: Modular engine architecture, async event dispatching, decoupled utility functions
- **Target OS**: Windows, macOS, Linux

## 🚀 Quick Start & Installation

### Prerequisites
- **Python**: Version 3.10 or higher installed
- **Git**: Installed for cloning repositories

### Setup Instructions
```bash
# 1. Clone the repository
git clone https://github.com/hsinidev/021-P2P-Local-File-Share-Server.git

# 2. Navigate to project directory
cd 021-P2P-Local-File-Share-Server

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Launch the Application
python app.py
```
*(Note: If `app.py` is absent, launch with `python main.py`)*
